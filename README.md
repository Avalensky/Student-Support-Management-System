# Student Support Management System

## Overview

The Student Support Management System is a Java console application developed using the MVC (Model-View-Controller) architecture.

The system allows users to manage student records, perform CRUD operations, and save/load student information from a text file.

## Features

- Add Students
- View All Students
- Update Student Information
- Delete Students
- Save Records to a File
- Load Records from a File
- MVC Architecture Implementation
- Object-Oriented Design

## Technologies Used

- Java
- MVC Design Pattern
- Object-Oriented Programming
- File Handling
- NetBeans IDE

- Separation of concerns using MVC

- Java collections
